# Nock

Nock is the voice and overlay agent for Mac and Windows: dictate into apps, get help where you work, and bring your coding agents and teammates together.

[Get Nock free](https://heynock.com/download/) · [Website](https://heynock.com/) · [Plans](https://heynock.com/pricing/) · [Documentation](https://docs.v3code.dev/nock/overview) · [Nock Social](https://social.heynock.com/)

Nock lives in the notch on Mac and a top bar on Windows. Hold a key to dictate, ask for help in the app in front of you, or talk to your coding chats from one place. The V3Code engine powers Nock’s coding capabilities.

## What you can do

- Dictate into text fields with local recognition and Light clean-up.
- Ask Nock to help with email, calendar, documents, code and the browser. Connected apps are included on paid plans.
- Keep Claude Code, Codex and other coding chats together in the Chat Manager.
- Hand work between teammates and agents with Team, available on every plan.
- Ask for a Canvas diagram, draw one yourself, organize cards and export standalone HTML.
- Build apps and widgets, or use cloud bots and routines on Pro and above. Cloud bots are Beta.

## Your AI, your choice

Use Nock’s included AI on Nock and above, connect an eligible existing account, bring your own API keys, or use a local model through Ollama. Account options include ChatGPT Plus/Pro through Codex, Claude Pro/Max, GitHub Copilot and SuperGrok. Eligibility, model availability and usage limits follow each provider’s plan.

The [connections directory](https://heynock.com/app-store/) separates account sign-in, API keys, local models and connected apps. An account login and an API key are different options.

## Start with the plan that fits

Free includes unlimited local dictation, Light clean-up, local voice and 25 talks a week with Nock; your own ChatGPT plan or API keys can provide more talking. Nock Own starts at $7.99 a month for people bringing their own AI and wanting connected apps. Nock starts at $14.99 a month with its own AI, Polished clean-up and cloud voice. Pro adds cloud bots, routines and X posting.

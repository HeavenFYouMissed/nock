Nock Own lifetime: $99 for the first 200 public spots, then $149. There are 1,000 spots total: 850 for sale and 150 reserved for creators and early testers. These are allocation sizes, not remaining inventory. Read the [live pricing page](https://heynock.com/pricing/) for confirmed availability.

Only Nock has a 7-day trial, with a card required: then $14.99 a month or $129.99 a year, depending on the selected period. Cancel before it ends to pay nothing. Other paid plans start paid, with no trial.

Team requires at least two people. Team collaboration itself is available on every plan; the Team subscription provides a shared bill.

## Nock Own

Includes: Full agent on eligible account, keys or local Ollama; Connected apps: 500 actions a day; One background worker; Team; Building with own Claude Code or Codex; Local dictation, Light clean-up and voice.

Excludes: Nock’s included AI; Polished clean-up; Cloud voice; Cloud dictation; Cloud bots; Posting to X. No free trial.

## Choose a plan

- Local dictation and trying Nock: Free.
- Your own AI plus connected apps: Own.
- Included AI, Polished clean-up and cloud voice: Nock.
- Cloud bots, routines, X posting or building on Nock’s AI: Pro.
- More building and background workers: Plus (4 workers), Max (8), Ultra (12).
- One bill for a group: Team.

Provider account eligibility and usage limits still apply. A local model does not make connected cloud apps offline.
